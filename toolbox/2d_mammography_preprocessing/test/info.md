# Testing

To test this tool, you will need to be connected to the HULAFE federated node where the FEM client has been deployed.

You can find an example input dataset and configuration files in:

```text
/data/tool_tests/2d_mammography_preprocessing/example_input
```

Run the tool and generate the output in:

```text
/sandbox
```

Finally, compare your generated results with the reference output located at:

```text
/data/tool_tests/2d_mammography_preprocessing/example_output
```
